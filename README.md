# Dev Quests 👾

**Level up your coding portfolio**

![Dev Quests Hero](public/hero.png)

## 📖 About The Project

**Dev Quests** is a curated platform designed to solve a common problem for developers: _"What should I build next?"_

Instead of endless tutorials or generic to-do lists, Dev Quests turns the journey of building a portfolio into an RPG-style adventure. We provide a collection of practical, real-world project ideas. "Quests" - that help you practice specific skills, learn new technologies, and build a body of work that stands out.

## 🎯 Our Goal

The primary goal of Dev Quests is to spark motivation and creativity. We believe that learning to code should be fun, engaging, and rewarding. By wrapping professional development challenges in a nostalgic **8-bit interface**, we aim to make the process of skill-building feel less like homework and more like playing your favorite classic game.

## 🚀 What It Does

- **Curated Challenges**: Browse a library of project ideas ranging from simple tools to complex applications.
- **Skill-Based Filtering**: Find quests that match your current skill level (Easy, Medium, Hard) or the tech stack you want to master.
- **Detailed Briefs**: Each quest comes with a clear set of requirements, user stories, and feature goals to simulate real-world specifications.
- **Immersive Experience**: Enjoy a fully themed retro environment with CRT effects, pixel art, and interactive animations that make browsing as fun as building.

## ✨ Why Dev Quests?

Building a portfolio shouldn't feel like a chore. Whether you are a beginner looking for your first project or a seasoned pro wanting to try a new framework, Dev Quests gives you the mission objective so you can focus on the code.

**Accept the challenge. Build something awesome.**
